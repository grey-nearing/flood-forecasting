maas package
============

Models-as-a-Service (MaaS): data fetching for the three operational global
flood forecast providers (Google FloodHub, Copernicus GloFAS v4, and
GEOGLOWS ECMWF v2), river-network reach snapping, and return-period
thresholds. The frontend presentation layer lives in
:mod:`frontend.maas_viewer`.

============================

flood summaries, timestamp-aligned hydrograph timelines, return-period
exceedance, and watershed polygons.
